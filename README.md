## 🌐 Live Preview
You can deploy this directly via **GitHub Pages**:
1. Go to repository **Settings** > **Pages**
2. Under **Build and deployment**, select `Deploy from a branch`
3. Select `main` branch and `/ (root)` folder, then click **Save**
